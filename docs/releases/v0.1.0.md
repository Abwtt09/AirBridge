# AirBridge 0.1.0 — First release

أول إصدار من **AirBridge** لاستقبال صوت الآيفون على Windows 11 عبر الشبكة المحلية.

- استقبال صوت AirPlay حقيقي، مع اتصال IPv4 وIPv6 محلي.
- اختيار مخرج الصوت، والتحكم بمستوى صوت التطبيق والكتم.
- التعرف على موديل الجهاز عند توفر معلوماته، مع رسم مناسب لـiPhone أو iPad.
- مظهر فاتح وداكن، وإعدادات محفوظة، وعمل في خلفية النظام.
- سجل اتصال للتشخيص واستعادة المستقبل عند تعطل المحرك.
- تنبيه داخل التطبيق عند صدور نسخة أحدث على GitHub، مع تنزيل وتثبيت بتوقيع تحقق.

**التنزيل:** اختر `AirBridge_0.1.0_x64-setup.exe` فقط. أرشيفات المصادر مخصصة
للمطورين. اختُبر الصوت المستقر والموديل الصحيح باستخدام iPhone 16 على iOS 27.
مشاركة الشاشة والملفات وتحسين المظهر والأداء ضمن الخطة المستقبلية.
المثبّت لا يحمل شهادة ناشر Windows؛ توقيع تحديثات التطبيق منفصل عنها.

---

AirBridge brings local wireless audio from a compatible iPhone to a Windows 11
PC. This first release focuses on receiving audio, with a native receiver rather
than a UI simulation.

## Included

- Real UxPlay/GStreamer AirPlay audio reception through Windows WASAPI.
- Local discovery, a customizable receiver name, and on-link IPv4/IPv6 handling.
- Windows output selection, per-app volume/mute, and three output-buffer presets.
- Connected-device identification and original iPhone/iPad illustrations when the
  client supplies a model identifier.
- Measured audio activity, light/dark/system appearance, onboarding and settings.
- Background tray operation, optional startup launch, and receiver crash recovery.
- In-memory connection logs with protocol-stage and packet-recovery diagnostics.
- Automatic GitHub update checks, an in-app availability notice, and signed
  download/install after user selection. Checks can be disabled; playback works offline.

## Verified on a real device

The user confirmed discovery, connection, stable audible playback and correct
model identification with **iPhone 16 on iOS 27**, using the Stable output buffer
and SteelSeries Sonar Media on the Windows PC. Live events showed decoded audio,
nonzero RMS and no engine error. Native tests additionally cover IPv6, startup,
port conflicts, output selection, process recovery, settings, shutdown and tray behavior.

This is a first public build, not a claim of universal iOS/router compatibility.
See [the detailed validation record](https://github.com/Abwtt09/AirBridge/blob/v0.1.0/docs/VALIDATION.md) for remaining device and
clean-machine tests.

## Download

Install **AirBridge_0.1.0_x64-setup.exe** from this release. WebView2 is required.
Allow the receiver on a trusted private LAN and select AirBridge from the
iPhone's **audio AirPlay** selector. Screen Mirroring is a separate future feature.

`latest.json` and the `.sig` file support in-app updates. `SHA256SUMS.txt` records
asset integrity. Source archives and SBOM files are for developers; they are not
needed to install or use AirBridge.

The installer is not Windows Authenticode-signed and may show an unknown-publisher
prompt. In-app update signatures use AirBridge's separate signing identity.

## Limitations and next steps

- Audio only. No screen mirroring, video, multi-room playback or file sharing.
- This is not a complete implementation of every AirPlay 2 feature.
- A trusted shared LAN and suitable firewall access are required.
- Output/name/buffer changes restart the receiver and require reconnecting.
- No guaranteed latency value; buffering and synchronization depend on the protocol,
  output device and network. Start with Stable if playback is interrupted.
- Hardware validation currently covers one iPhone/Windows setup. Sleep/resume,
  broader router/iPad compatibility and a clean offline Windows VM remain pending.

Planned work includes screen sharing, AirDrop-style local file transfer (without
claiming Apple AirDrop protocol compatibility), appearance/accessibility and
performance improvements. See [the roadmap](https://github.com/Abwtt09/AirBridge#الخطة-المستقبلية).
